개인정보처리방침

THE YEARS Backup은 개인 기록의 복구용 사본을 Google Drive에 보관하기 위한 소유자 전용 자동화 도구입니다.

시행일: 2026년 11월 11일

1. 도구의 목적

THE YEARS Backup은 Cloudflare D1의 기록 데이터와 Cloudflare R2의 첨부 사진을 Google Drive에 백업하여 소유자가 기록을 복구할 수 있도록 지원합니다. 일반 방문자에게 Google Drive 접근을 요청하지 않습니다.

2. Google 사용자 데이터 접근 및 이용

Google OAuth를 통해 소유자의 Google Drive 접근 권한을 부여받습니다. rclone은 Google Drive의 폴더·파일 메타데이터를 확인하고, 백업 폴더를 생성하며, SQL 및 사진 백업 파일을 업로드하고 백업 상태를 확인하는 데 이 권한을 사용합니다. 권한 범위가 더 넓더라도 THE YEARS 백업 운영과 복원 이외의 목적으로 다른 Drive 파일을 탐색·활용하지 않습니다.

3. 저장되는 데이터와 위치

  • 백업 파일: 소유자가 관리하는 Google Drive의 THE YEARS BACKUP 폴더에 저장됩니다. 이 파일에는 기록 내용이나 사진 등 개인적인 정보가 포함될 수 있습니다.
  • 인증 설정: rclone OAuth 인증 설정은 소유자가 생성하며, 자동화 실행을 위해 GitHub Actions의 암호화된 Secrets에 저장됩니다. 공개 GitHub 저장소나 이 안내 페이지에 인증 토큰을 게시하지 않습니다.
  • 작업 로그 및 임시 파일: GitHub Actions 실행 중 생성될 수 있습니다. 자동화에서 생성하는 GitHub 백업 아티팩트는 구성된 보존 기간에 따라 만료됩니다.

4. 공유 및 제3자 제공

Google Drive에서 얻은 사용자 데이터를 광고, 분석, 판매 또는 제3자 마케팅 용도로 사용하거나 판매하지 않습니다. 파일 전송과 보관을 위해 Google Drive, GitHub Actions 및 Cloudflare 인프라가 사용됩니다. 소유자가 직접 공유 설정을 변경하지 않는 한 백업 파일을 공개적으로 배포하도록 설계되어 있지 않습니다.

5. 보존 및 삭제

Google Drive의 백업 파일은 소유자가 삭제하거나 보관 정책을 변경할 때까지 남을 수 있습니다. 소유자는 Google Drive에서 백업 파일을 삭제하고, Google 계정의 앱 접근 권한을 철회할 수 있습니다. GitHub Actions Secrets의 인증정보는 저장소 관리 설정에서 교체하거나 삭제할 수 있습니다. 앱 접근 철회는 이미 생성된 Google Drive 백업 파일을 자동으로 삭제하지 않습니다.

6. 보안

OAuth 인증정보는 HTTPS 인증 절차와 GitHub Actions Secrets를 이용해 다룹니다. 백업 파일과 자동화 계정 접근은 소유자만 관리하도록 의도했습니다. 어떤 온라인 저장·전송 방식도 절대적인 보안을 보장하지 않으며, 필요한 경우 소유자가 권한을 철회하거나 인증정보를 재발급할 수 있습니다.

7. Google API 사용자 데이터 정책

Google API에서 얻은 사용자 데이터는 이 방침에 명시된 백업 기능에만 사용하며, Google API Services User Data Policy의 Limited Use 요건에 따라 취급합니다.

8. 문의 및 변경

이 도구는 개인 소유자용이며, 관련 문의는 Google OAuth 동의 화면에 표시된 사용자 지원 이메일로 할 수 있습니다. 데이터 처리 방식이 변경되면 이 페이지를 업데이트합니다.
