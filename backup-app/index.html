THE YEARS Backup

개인 아카이브 THE YEARS의 기록을 오래 보관하기 위한 백업 도구입니다. Cloudflare에 저장된 데이터베이스와 사진 파일의 백업본을 소유자가 관리하는 Google Drive에 정기적으로 보관합니다.

무엇을 하나요?

  • Cloudflare D1 데이터베이스를 SQL 파일로 내보냅니다.
  • Cloudflare R2에 저장된 사진을 백업 파일로 복사합니다.
  • GitHub Actions와 rclone을 사용해 Google Drive의 THE YEARS BACKUP 폴더에 백업 파일을 업로드합니다.
  • 소유자가 데이터 복구를 위해 백업 파일을 확인하거나 내려받을 수 있도록 합니다.

Google Drive 권한 사용

Google Drive API는 백업 대상 폴더 확인, 폴더 생성, 파일 업로드 및 백업 파일 확인에 사용합니다. 현재 연결 방식은 rclone의 Google Drive 접근 권한을 사용하지만, 앱의 목적은 THE YEARS 백업 작업에 한정됩니다.

사용 대상

이 도구는 THE YEARS 소유자의 개인용 자동 백업을 위해 구성되었습니다. 일반 방문자의 Google 계정 로그인을 요구하지 않으며, 개인 기록 열람 기능이나 공개 파일 공유 기능을 제공하지 않습니다.

개인정보 및 보안

Google 계정 인증정보는 공개 사이트 페이지에 포함하지 않습니다. 백업 자동화에 사용하는 인증 설정은 GitHub Actions Secrets를 통해 관리합니다. Google Drive 사용자 데이터의 접근·이용·보관·삭제 방식은 개인정보처리방침을 참고하세요.

이 페이지는 서비스의 기능을 설명하는 안내 페이지이며, 백업 실행이나 Google 로그인 기능을 포함하지 않습니다.
